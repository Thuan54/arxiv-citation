# Về thư mục
Thư mục `docs` được sử dụng để lưu trữ các đặc tả thiết kế, nguyên lý hoạt động của **Project Arxiv Crawler**

Đối tượng:
- Cho chính các thành viên trong nhóm, được sử dụng để trao đổi các thông tin giữa các thành viên được phân công các công việc khác nhau
- Dành cho ngưởi có nhu cầu tìm hiểu về dự án của nhóm

## Cấu trúc thư mục

```
docs/
|___ 01_crawling/       # tài liệu milestone 1
|___ 02_parsing/        # tài liệu milestone 2
|___ 03_matching/       # tài liệu milestone 3
|___ data/              # tài liệu về dữ liệu thu được
|       |___ metadata/
|       |___ parsing/
|       |___ matching/
|
|___ README.md
```
